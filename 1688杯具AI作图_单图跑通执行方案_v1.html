00 · 三句结论

  1. 备案：这个阶段不用。 服务器在首尔，不属于工信部 ICP 备案管辖；内部 1–3 人、不售卖、不公开，直接开用。
  2. 钱：0 元就够跑通，而且只需 1 个账号。 百炼北京新用户每模型 100 万 Token 免费；2026-11-06 新发现：百炼自带生图免费额度（qwen-image-3.0 / 3.0-pro 各 10 张），BytePlus 不再是单图跑通的前置条件。单图阶段连对象存储都不用接。上一版说的 200–300 元是「10 SKU 打样 + 上线准备」预算，现在用不上。
  3. 拼装已完成并实跑通过。 m0/ 骨架把 GitHub 现成 MIT 代码真正搬进来改造成 1688 校验器，一条命令 0.2 秒跑完 10 个环节，产出三张成品图 + CDR 可编辑 SVG + 合规报告 + 生成存证，成本 0 元。

01 · 备案：对，不用，但有边界

判定标准是「服务器物理位置」，与域名注册地、用户是谁无关。 境外节点不归《非经营性互联网信息服务备案管理办法》管辖，云平台不会阻断 80/443。你已有的国内备案域名和服务器是好牌，但这一轮完全用不上，留着切换时用。

情形要不要办
首尔节点 + 1–3 人内部 + 不售卖 + 不公开链接不用 ICP 备案
换成国内节点（正式上线）必须；用你已备案的域名走接入备案变更即可，比新备案快
境外节点向境内用户有偿提供信息服务仍需经营性 ICP 许可（与服务器位置无关）——你不售卖，不触发
域名实名认证国内注册商强制；你已有备案域名，肯定已完成
公安联网备案面向境内公开运营才需开通 30 日内办；内部试用不属于；一旦对外要补

三个别踩的坑

  • 别给这个子域挂国内 CDN / 国内 COS 自定义域名 / 国内 OSS 绑定域名——这些会校验备案或跨境错位。图片先放服务器本地盘，等切国内节点再上 COS。
  • 别把链接对外发、别挂 1688 店铺宣传、别放公开注册入口。「不公开」是这个阶段免备案的前提。
  • 首尔到国内有延迟，2–3 人用可以接受，但别承诺稳定性；正式服务必须换国内节点。
注意：图片最终要上 1688 商品页，那就是公开传播，所以合规四件套（极限词、AI 标识、1688 图规、字体白名单）现在就必须埋进流程——骨架里已经埋好并跑通了，不能等对外再做。

07 · 待确认与已知风险

  1. 杯子还原是唯一生死线：offline 的白底阈值抠图只对白底不透明商品有效；玻璃/反光杯必须靠 live 的 isnet-general-use 或更好的模型，第 5–6 步就是在验这个。
  2. 标识落位冲突：1688 主图禁文字水印，与《标识办法》要求的显式标识有张力。骨架默认把显式标识放详情图 + 披露文件、主图保持干净；正式上架前按商家后台现行规则确认。
  3. 图规阈值（800×800、白底 98%、主体占比 60–94%、3MB）是可改基线，不是平台最终条文，需以你的商家后台为准。
  4. 首尔机这轮还没动；需要你给公网 IP 才能出 DNS A 记录与 Caddy/Docker 配置。
  5. GitHub 未接 token：本轮关键仓库已核实并浅克隆到 _github_refs/；以后要批量扫仓库/自动同步上游再接不迟。
