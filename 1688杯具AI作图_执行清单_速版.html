4. 首尔节点专用配置（开发期）

  • 对象存储用腾讯云 COS 首尔桶（ap-seoul），与服务器同地域内网互通，避开"首尔机 + 国内 OSS"的跨境错配。
  • 模型走就近地域：百炼新加坡/国际域名、BytePlus ModelArk 国际域名；国内百炼/方舟 Key 留到正式上线启用。
  • 因此模型适配层第一天就要做成配置切换（换 base_url / Key / 模型 ID 即可切国内），这是首尔机不浪费的关键。
  • 每次换地域先跑一次单图调用，确认模型 ID 可用、单价、限流与返回格式。

5. DNS 与安全（你手动，约 5 分钟）

  1. DNSPod / 腾讯云 DNS 控制台 → 主域名 → 添加记录：类型 A，主机记录 img，记录值填首尔服务器公网 IP，TTL 600。
  2. 验证 nslookup img.主域名 解析到该 IP；Caddy 配置该子域后会自动签发 HTTPS 证书。
  3. 安全：只放行 80/443，SSH 改密钥登录并禁密码；PostgreSQL 只监听本机；COS 桶保持私有，只发临时签名。
  4. 主域名若已备案，把子域解析到海外 IP 只用于开发/内测，不要挂正式商家入口；正式入口用备案后的国内节点。

6. 门槛与止损

  • Stage A：50 元、10 SKU、1–2 天。10 款过 7 款进开发；4–6 款走保守路线只服务自己；≤3 款暂停建站。
  • 主体形变 / Logo 变字 = 0 容忍；透明杯不达标走人工抠图并计成本。
  • 任何一步不达标，损失止步在 50 元 + 1–2 天，不进大开发。
